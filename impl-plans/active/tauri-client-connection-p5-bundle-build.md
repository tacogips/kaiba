## Intent and context

Run the full recorded gates on the integrated tree, then build `Kaiba.app`
and prove that its bundled `kaiba` service is fresh. This plan verifies and
builds only. It edits no source. Build facts, checked in the repository:

- `web/src-tauri/tauri.conf.json` sets `beforeBuildCommand` to
  `bash ../scripts/build-tauri-local-service.sh release && bun run build`.
- The script runs `swift build -c release --triple arm64-apple-macosx14.0
  --product kaiba` and copies the result to
  `web/src-tauri/local-service/kaiba-aarch64-apple-darwin`.
- `web/src-tauri/tauri.macos.conf.json` sets `externalBin:
  ["local-service/kaiba"]`. Tauri installs the triple-suffixed file as
  `Kaiba.app/Contents/MacOS/kaiba`.
- The bare `web/src-tauri/local-service/kaiba` (2026-09-11) is a leftover.
  It is not bundled. Leave it alone.

## Steps (strictly in this order, all in the foreground, each tee'd)

Each step tees its output into `tmp/tauri-client-connection/P5/logs/<n>-<name>.log`
and records its exit code in `progress.md`.

1. `git rev-parse HEAD`, `git status --short`, and
   `git diff --stat f02c4fe -- Sources Package.swift Package.resolved`. The
   last must be empty. A non-empty result is a blocker: record it and stop.
2. `cd web && bun test src`: exit 0. Record the pass and fail counts; pass
   must be greater than 0 and fail must be 0.
3. `cd web && bunx vitest run`: exit 0. Record the test-file and test
   counts.
4. `bunx tsc --noEmit -p web`: exit 0.
5. `cd web && bun run lint`: exit 0.
6. `mise run tauri:check`: exit 0. This runs cargo fmt --check, check and
   clippy -D warnings.
7. `touch tmp/tauri-client-connection/P5/logs/build-start.marker`, then
   `date -u` into the log.
8. `mise run tauri:build`: exit 0. Use a timeout of up to 60 minutes and
   poll until it exits. Run it with signing variables removed from the
   environment, for example `env -u APPLE_SIGNING_IDENTITY -u
   APPLE_CERTIFICATE -u APPLE_ID -u APPLE_PASSWORD -u APPLE_TEAM_ID -u
   TAURI_SIGNING_PRIVATE_KEY mise run tauri:build`, so the result stays an
   unsigned local build.
9. Freshness checks. Let `APP=web/src-tauri/target/release/bundle/macos/Kaiba.app`.
   - `test -d "$APP"`
   - `test -x "$APP/Contents/MacOS/kaiba"`
   - `cmp "$APP/Contents/MacOS/kaiba" web/src-tauri/local-service/kaiba-aarch64-apple-darwin`
     exits 0
   - `test "$APP/Contents/MacOS/kaiba" -nt tmp/tauri-client-connection/P5/logs/build-start.marker`
   - `test web/src-tauri/local-service/kaiba-aarch64-apple-darwin -nt .../build-start.marker`
   - `test web/dist/index.html -nt .../build-start.marker`
   - `stat -f '%Sm %z %N'` on each of these files
   - `shasum -a 256` of both binaries
10. Write `evidence.md`. It holds one record per command, each with the
    command, the exit code, the full log path and the counts. It also holds
    the bundle path, the freshness results, HEAD, and the empty Swift diff
    from step 1.

## Pitfalls (what not to do)

- Do not run `open`, `Kaiba.app/Contents/MacOS/Kaiba`, or `kaiba serve`
  with default paths. Local mode and the default store would touch
  `~/Library/Application Support/com.tacogips.kaiba/local` or `~/.kaiba`. No
  runtime launch is required by this plan.
- Do not use `mise run web:check` as the recorded test command. You may run
  it in addition, as a separate record.
- Do not edit source to make a gate pass. A failure is recorded as
  `status: blocked: <step> <exit> <log path>`, with the failing test names,
  for serial reconciliation.
- Do not delete `web/src-tauri/local-service/kaiba`, the old bundle, or any
  tracked file. Do not run `git add`, `git commit` or `git push`.
- If `swift package resolve` (run inside the script) rewrites
  `Package.resolved`, record it as a blocker. Do not commit or revert it
  yourself.
- `tauri build` may print a warning about missing signing or updater keys.
  That is expected for an unsigned build and is not a failure, as long as
  the exit code is 0.
- No detached processes. If the tool returns a running handle, poll it
  until it exits.

## Done criteria

- Steps 2 to 9 all exit 0, and the counts in steps 2 and 3 are greater
  than 0.
- `evidence.md` names
  `web/src-tauri/target/release/bundle/macos/Kaiba.app` and records that
  the `cmp` passed and that both binaries and `web/dist/index.html` are
  newer than the marker.
- `tmp/tauri-client-connection/P5/progress.md` ends with `status: done`.
